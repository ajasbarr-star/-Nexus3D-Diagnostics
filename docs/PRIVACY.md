# Privacy and data handling

- Store diagnostic events locally by default.
- Do not upload automatically unless the user explicitly enables sync.
- Provide controls to pause/disable sync and choose Wi-Fi-only behavior.
- Never collect passwords, access tokens, project source assets, or unrelated personal content.
- Prefer pseudonymous installation IDs over hardware identifiers.
- Make report export and deletion user-controlled.
- Apply retention limits and protect transport with HTTPS when cloud sync is implemented.
- Treat imported reports and IPC payloads as untrusted input; validate schema, size, and fields.
